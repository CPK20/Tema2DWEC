¿Por qué comparten motores los navegadores mencionados?

Muchos de los navegadores utilizan motores de renderizado similares porque esto permite aprovechar tecnologías ya desarrolladas y mantener una buena compatibilidad con los estándares web. Chrome, Edge y Opera utilizan Chromium y el motor Blink, Firefox utiliza Gecko y Safari utiliza WebKit, por lo que no todos los navegadores dependen de Chromium. Para los desarrolladores web, esta diversidad hace que tengamos que probar las cosas en distintos navegadores para asegurarnos de que todo funciona correctamente.

Ejemplo de compatibilidad

CSS Nesting

CSS Nesting permite escribir reglas CSS anidadas dentro de otras reglas, de forma similar a cómo se trabaja con preprocesadores como Sass. Su compatibilidad ha sido diferente según el navegador y su versión.

Según Can I Use, Chrome ofrece soporte completo desde la versión 120, Firefox desde la versión 117 y Safari desde la versión 17.2. Por ejemplo, Chrome 119 no tenía soporte completo para esta característica.
